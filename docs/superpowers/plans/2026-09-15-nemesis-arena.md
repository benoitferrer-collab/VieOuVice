# Némésis asynchronous arena implementation

Approved scope: invitations between accepted friends, animated turn-based combat with own HP/energy, 24h per turn, push deep links to exact duel, history, surrender, rematch. Existing weekly rivalry retained as secondary information. No git/push/production SQL.

## Binding contracts and rules
RPC get_arena() => {duels:ArenaDuel[]}; get_arena_duel(p_duel_id uuid) => ArenaDuel. Mutations arena_invite(p_friend_id uuid,p_request_id uuid), arena_respond(p_duel_id uuid,p_accept boolean), arena_move(p_duel_id uuid,p_move text,p_expected_turn integer), arena_surrender(p_duel_id uuid) all return ArenaDuel.
ArenaDuel {id,challenger_id,opponent_id,status:'pending'|'active'|'finished'|'declined'|'expired'|'cancelled',turn_user_id:string|null,turn_number:number,deadline:string,created_at:string,winner_id:string|null,finish_reason:string|null,fighters:[{user_id,nickname,avatar,hp,energy,guard:boolean},...],moves:[{turn:number,actor_id,move,damage:number,healing:number,created_at:string}],reward:number}.
HP100 energy2 max4. quick damage12 energy+1; heavy damage24 cost2; guard energy+2 and halves next incoming damaging move (ceil). special cost3: avatar0 damage20 heal8; avatar1 damage26; avatar2 damage12 heal16; avatar3 damage16 heal12. Guard persists until next damaging hit, not stackable. Health capped100. Accepted opponent takes first turn. After each valid move turn_number increases (first expected=1), turn passes, deadline24h. At40 moves finish by HP (draw if equal). Timeout/surrender finished, opponent wins, no reward. Invitation expires after24h. Reward KO/turnlimit only when each made >=3 moves: winner10 Eclats, capped30 per Paris day, unique duel grant. No XP or cosmetic combat modifiers. No real excess action gives power.
Only one pending/active duel per unordered pair, max3 open per player, max10 invites/day. Friendship/block/suspension checked on reads/mutations/push authorization; invalid duels cancel. Pending decline no reward. Rematch creates fresh invitation via same RPC. Participant-only detail/history, latest30 via list. Actor-generated notifications 'arena_invite','arena_turn','arena_finished', target_tab nemesis, add arena_duel_id public.notifications nullable UUID. Notification payload generic, push authorized only while relevant friendship/status/turn holds, respects notify_duels and quiet hours. Existing immediate outbox trigger/cron reused. History preserved except account purge cascades; reward ledger of other player must remain when opponent deleted.
